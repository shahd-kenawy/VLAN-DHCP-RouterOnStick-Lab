# VLAN-DHCP-RouterOnStick-Lab

## Overview
This project is a Cisco Packet Tracer lab demonstrating a network design that uses VLAN segmentation, DHCP, and Router-on-a-Stick configuration.

## What This Lab Covers
- Creating multiple VLANs to segment the network into separate broadcast domains
- Configuring a Router-on-a-Stick setup to allow inter-VLAN routing through a single router interface
- Setting up DHCP so devices in each VLAN automatically receive IP addresses
- Verifying connectivity between devices across different VLANs

## Tools Used
- Cisco Packet Tracer 9.0.0

## File
- Lab1_VLAN_DHCP_RouterOnStick.pkt — the complete network topology file, open it in Cisco Packet Tracer to view and interact with the configuration.
